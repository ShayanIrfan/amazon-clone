Yes — multiple admins are fully supported. There's no single-admin limit.

- Admin is just a **`role: "admin"` field on the user** — any number of users can have it.
- **`create-admin`** can be run for as many emails as you like. It creates a new admin, or **promotes an existing account** to admin (and resets its password if you pass one). So an existing shopper can be made an admin too.
- The admin middleware checks the role **from the database on every request**, not from the session — so promoting or removing an admin takes effect immediately, and revoking access (`role` back to `user`) locks them out on their next action.

One deliberate guardrail: **the API itself has no "make someone an admin" endpoint** — admins can't create other admins from inside the panel. The only way to grant the role is the `create-admin` script run against the database directly. That's a security choice (a compromised admin session can't mint more admins), not a limitation on how many admins can exist.
