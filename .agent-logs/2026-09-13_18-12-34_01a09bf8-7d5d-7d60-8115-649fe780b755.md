For your Amazon-clone frontend with an Express backend, I suggest:

- React + TypeScript
- Vite for bundling/dev server
- React Router for pages
- Tailwind CSS for styling
- TanStack Query for API/server state
- Zustand for small client state such as cart UI, filters, and auth status
- Zod for validating API responses/forms
- Native `fetch` or Axios for HTTP requests

React’s current docs show Vite as the straightforward from-scratch setup, and Create React App is deprecated. citeturn0search3turn0search1 Vite also has an official React TypeScript template. citeturn0search6 Tailwind provides an official Vite plugin. citeturn1search1

Start with:

```bash
npm create vite@latest frontend -- --template react-ts
cd frontend
npm install react-router-dom @tanstack/react-query zustand zod
npm install tailwindcss @tailwindcss/vite
```

For this assignment, I would avoid Next.js initially because Express already handles your backend and Vite keeps the frontend simpler. Use Next.js later only if SEO/server rendering becomes important.
